# 📚 NextSemNIOS: Official NIOS Open Schooling Learning Portal

A dedicated platform for **National Institute of Open Schooling (NIOS)** Secondary (Class 10) & Senior Secondary (Class 12) students with official course modules, guided question papers, chapter practice worksheets, and interactive test studios.

- **Engineered by**: Er. Manoj Kumar ([NextSem](https://nextsem.online))

---

## 🌟 Key NIOS Modules
- **NIOS Secondary (Class 10)**: Mathematics (211), English (202), Home Science (216), Science & Technology (212).
- **NIOS Senior Secondary (Class 12)**: Chemistry (313), Physics (312), Accountancy (320), Economics (318), History (315).
- **Interactive Practice Studios**: Fill-in-the-blanks, numerical problem solvers, and line-by-line MCQ testing engines.
- Authentic 3D NCERT & NIOS Textbook Covers for instant physical book recognition.
- Direct chapter PDF access to **NCERT Official CDN**, **NCERT Online Textbook Portal**, and **Google Drive Cloud Repository**.
- Clean breadcrumb navigation trail, instant topic search, bookmarks, and PWA offline capabilities.

## 🚀 Tech Stack & Infrastructure

- **Frontend Framework**: React 19 + TypeScript + Vite
- **Mobile Foundation**: Capacitor 8 (Android Target)
- **Static Interactive Modules**: HTML5, Vanilla CSS3 (Custom Dark Glassmorphic Theme), ES6+ JavaScript
- **Zero-Dependency Server**: Node.js HTTP server supporting multi-port fallback (ports 3002 & 3005)
- **Icons & Animation**: Lucide React (`lucide-react`) & Canvas Confetti

│   └── project-status.cjs     # Real-time metrics and roadmap progress reporter
├── src/                       # React 19 + TypeScript application source code
│   ├── components/            # UI components (Reader, Dashboards, Modals, Navbars)
│   │   ├── interactive/       # Embedded React competency test and lab views
│   │   └── pages/             # Dedicated drawer and sub-portal views

│   └── utils/                 # Storage, state merging, and helper utilities
├── index.html                 # Main Vite SPA entry point
└── package.json               # Scripts, dependencies, and project metadata

## 💻 Local Setup & Execution

```bash
# Clone the repository
git clone https://github.com/nextsemacademy-max/studyguide.git
cd studyguide

# Install dependencies
npm install

# Start Vite React development server
npm run dev

# Run Oxlint linter
npm run lint

# Compile production build
npm run build

# Archive chat transcript
npm run save-chat
```
