## 🎯 Key Interactive Features Built
1. **Dynamic Fisher-Yates Option Shuffling Engine**:
   - Every time a user opens the test, retakes the quiz, starts a timed exam, or clicks **"🔀 Reshuffle Options"**, all 4 options (A, B, C, D) are dynamically and pseudo-randomly permuted.
   - Hinglish and English options stay 100% in sync using synchronized permutation maps.
   - `correctIndex` is automatically re-indexed so answer grading is always 100% accurate.
   - Static dataset options in `class11StatsTestData.ts` are also balanced evenly (approx 25% each across A, B, C, D).
2. **Random Question Order Toggle**:
   - Optional toggle for shuffling the question order from 1–30 so questions never appear in predictable order.
3. **Bilingual & Hinglish Language Engine**:
   - Full student-friendly Hinglish question prompts, options, formula breakdowns, and in-depth NCERT textbook page references.
   - One-click toggle between **🇮🇳 Hinglish** and **🇬🇧 English**.
4. **Dual Test Modes**:
   - 🎓 **Practice & Learn Mode**: Instant answer check, step-by-step Hinglish explanations, Pro Tips & NCERT citations.
   - ⏱️ **Timed Exam Mode**: 20-minute live countdown timer, question palette navigation (1–30), real-time progress bar, scorecard analytics, and confetti celebration.
5. **Chapter-wise Filter**:
   - Filter by specific chapter (Ch 1, Ch 2, Ch 3, Ch 4) or all 30 questions.
6. **Print / PDF Ready**:
   - Clean printable test paper with question blocks, blank answer grids, and formula cheat sheets.
7. **Class 11 Subject Integration**:
   - Added *Statistics for Economics (`kest1dd`)* as a core subject in `ncertData.ts` and created a direct-launch hero card on the main dashboard.
