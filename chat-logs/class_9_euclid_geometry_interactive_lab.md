# Class 9 Maths Chapter 5: Introduction to Euclid's Geometry Interactive Lab

## Summary of Changes
- Built interactive animated visual simulators for **NCERT Class 9 Mathematics Chapter 5 (`iemh105.pdf`)**:
  - **Interactive 5 Postulates Lab**:
    1. **Postulate 1**: Click-and-drag interactive line connecting 2 points with uniqueness proof (Axiom 5.1).
    2. **Postulate 2**: Animated ray extension simulator producing terminated line segments indefinitely in both directions.
    3. **Postulate 3**: Dynamic compass needle and radius ($r$) adjuster for circle constructions.
    4. **Postulate 4**: Real-time orientation angle rotation demonstrating $90^\circ$ right angle congruence.
    5. **Postulate 5**: Transversal line angle sliders ($\angle 1, \angle 2$) dynamically computing interior angle sums ($< 180^\circ$ left intersection vs $= 180^\circ$ parallel vs $> 180^\circ$ right intersection) and demonstrating Playfair's Axiom.
  - **Proposition 1.1 Equilateral Triangle Construction**: 4-step auto-playing ruler and compass geometric proof with intersecting circles.
  - **7 Axioms Deck**: Interactive cards with algebraic formulas and real-world examples.
  - **Interactive Knowledge Check Quiz**: Instant feedback with pedagogical explanations.
- Connected seamlessly into the web app routing (`?view=euclid` or clicking the glowing chapter button).
