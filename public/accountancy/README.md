# 📊 Accountancy — Class 11 Interactive Learning Platform

An interactive, visual educational guide and practice platform for **Class 11 Accountancy and Beginners Financial Accounting**.

---

## 🚀 Features

- **The 3 Golden Rules of Accounting**: Deep breakdown of Personal, Real, and Nominal accounts with concrete business examples.
- **Modern Approach (DEAL & CLEAR)**: Fast visual balance framework for Assets, Liabilities, Capital, Revenue, and Expenses.
- **Interactive Transaction Solver**: Step-by-step transaction analysis simulator with real-time journalizing.
- **Master Journal Ledger**: Full multi-column journal table with balanced debits and credits.
- **Practice Exercises & Quizzes**: 15+ real-world transaction problems with hints, full solutions, and instant feedback quizzes.
- **Basics of Accounting Test Bank (30 MCQs)**: Interactive 30-question quiz with instant feedback, in-depth explanations, topic filters, and live score tracking.
- **Dark/Light Mode & Print Support**: Optimized for reading and printing study cheat sheets.

---

## 🛠️ Tech Stack

- **HTML5 / CSS3 / Vanilla JavaScript**
- **Vite** (Fast Local Development Server)
- **GitHub Markdown** curriculum notes

---

## 💻 Getting Started Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/nextsemacademy-max/Accountancy.git
   cd Accountancy
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local dev server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
