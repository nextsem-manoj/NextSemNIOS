5. Solution (Given 15 cot A = 8): Total: 2M
• 15 cot A = 8 ⇒ cot A = 8/15 = Adjacent Side / Opposite Side. [0.5M]
• In right-angled triangle: Hypotenuse = √((Adjacent)2 + (Opposite)2) = √(82 + 152) = √(64 + 225) = √289 = 17. [0.5M]
• Therefore, sin A = Opposite / Hypotenuse = 15/17. [0.5M]
• And sec A = Hypotenuse / Adjacent = 17/8. [0.5M]
6. Solution (Evaluate 2 tan2 45° + cos2 30° − sin2 60°): Total: 2M
• Standard table values: tan 45° = 1, cos 30° = √3/2, sin 60° = √3/2. [0.5M]
• Substituting values:
   E = 2(1)2 + (√3/2)2 − (√3/2)2 [1M]
• Since (√3/2)2 − (√3/2)2 = 0, we get:
   E = 2(1) + 0 = 2. [0.5M]
7. Solution (In right ΔABC, AB = 5 cm, ∠C = 30°): Total: 2M
• To find BC: tan 30° = AB / BC ⇒ 1/√3 = 5 / BC ⇒ BC = 5√3 cm. [1M]
• To find AC: sin 30° = AB / AC ⇒ 1/2 = 5 / AC ⇒ AC = 10 cm. [1M]

Section C • Conceptual Application Solutions (CBSE PYQs) 6 Marks (2 × 3M)
8. Solution (Given tan θ = 4/3, evaluate (4 sin θ − 3 cos θ) / (4 sin θ + 3 cos θ)): Total: 3M
Method 1 (Dividing numerator and denominator by cos θ):
• Dividing each term by cos θ: [1M]
   E = (4 (sin θ / cos θ) − 3) / (4 (sin θ / cos θ) + 3) = (4 tan θ − 3) / (4 tan θ + 3)
• Substitute tan θ = 4/3: [1M]
   Numerator = 4(4/3) − 3 = 16/3 − 3 = (16 − 9)/3 = 7/3
   Denominator = 4(4/3) + 3 = 16/3 + 3 = (16 + 9)/3 = 25/3
• Simplifying the fraction: [1M]
   E = (7/3) / (25/3) = 7/25.
9. Solution (Given sin(A − B) = 1/2 and cos(A + B) = 1/2): Total: 3M
• From standard angle values: sin 30° = 1/2  ⇒  A − B = 30° … (Equation 1) [1M]
• Also: cos 60° = 1/2  ⇒  A + B = 60° … (Equation 2) [1M]
• Adding (1) and (2):
   (A − B) + (A + B) = 30° + 60° ⇒ 2A = 90° ⇒ A = 45° [0.5M]
• Substituting A = 45° into Equation 2:
   45° + B = 60° ⇒ B = 60° − 45° ⇒ B = 15°. [0.5M]
• (Verification: A + B = 60° ≤ 90° and A > B holds true).
Section D • Right Triangle & Multi-Ratio Problem Solution 4 Marks (1 × 4M)
10. Solution (In ΔPQR, ∠Q = 90°, PQ = 5 cm, PR + QR = 25 cm): Total: 4M
Part (a): Finding QR and PR: [2M]
• Let QR = x cm. Then PR = (25 − x) cm.
• In right ΔPQR, by Pythagoras Theorem: PR2 = PQ2 + QR2
   (25 − x)2 = 52 + x2
   625 − 50x + x2 = 25 + x2
   625 − 25 = 50x ⇒ 50x = 600 ⇒ x = QR = 12 cm. [1M]
• Hypotenuse PR = 25 − 12 = 13 cm. [1M]
Part (b): Determining the trigonometric ratios: [2M]
With respect to angle P: Opposite Side = QR = 12 cm, Adjacent Side = PQ = 5 cm, Hypotenuse = PR = 13 cm.
• sin P = Opposite / Hypotenuse = 12/13 [0.5M]
• cos P = Adjacent / Hypotenuse = 5/13 [0.5M]
• tan P = Opposite / Adjacent = 12/5 [1M]
