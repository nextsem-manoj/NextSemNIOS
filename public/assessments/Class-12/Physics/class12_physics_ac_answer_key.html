Section A Solutions • Core Conceptual Definitions 6 Marks
A1. Root Mean Square (RMS) Current & Measurement Principle: [1 Mark]
Definition: RMS current is that steady direct current (DC) which produces the same average heating effect (Joule heat) in a given resistor in a given time as is produced by the alternating current in the same resistor during one complete cycle.
Measurement: Moving coil DC meters read the average value over a full cycle (⟨i⟩ = 0). Hence, AC ammeters utilize the heating effect of current (H ∝ i², which is always positive) through hot-wire instruments.
A2. Inductive vs. Capacitive Reactance: [1 Mark]
XL = ωL = 2πνL: Opposition offered by inductor to AC. It is directly proportional to frequency (XL ∝ ν). For DC (ν = 0), XL = 0.
XC = 1/(ωC) = 1/(2πνC): Opposition offered by capacitor to AC. It is inversely proportional to frequency (XC ∝ 1/ν). For DC (ν = 0), XC = ∞ (blocks DC completely).
A3. Impedance (Z) Definition & Dimensions: [1 Mark]
Definition: Impedance is the total effective opposition offered by an AC circuit containing a combination of resistance, inductance, and capacitance to the flow of alternating current: Z = √[R² + (XL - XC)²].
Unit & Dimensions: SI unit is Ohm (Ω). Dimensions: [M L² T¯³ A¯²]. At resonance (XL = XC), Z = R (minimum).
A4. Wattless Current: [1 Mark]
Definition: The component of alternating current in an AC circuit which consumes zero average electrical power over a complete cycle is called wattless current.
Condition: Occurs when the phase difference between voltage and current is φ = π/2 rad (90°) (pure inductor or capacitor), so that power factor cos φ = cos 90° = 0, giving P = V I cos φ = 0.
A5. Power Factor & Transmission Significance: [1 Mark]
Definition: The cosine of the phase angle φ between voltage and current, cos φ = R/Z.
Transmission Impact: Since power P = V I cos φ, to deliver a given power P at voltage V, current is I = P / (V cos φ). If cos φ is small (low power factor), current I must be very large, leading to immense Joule heating loss (I²R) along transmission power lines.
A6. Quality Factor (Q-Factor): [1 Mark]
Definition: Q-factor measures the sharpness of resonance in a series LCR tuning circuit: Q = ω0L / R = (1/R) √(L/C). A higher Q-factor ensures that the circuit is highly selective, tuning sharply to the desired radio frequency channel while rejecting adjacent frequencies.
Section C (Part I) Solutions • Core Mathematical Derivations 8 Marks
A7. Derivation of RMS Current from Joule Heating: [4 Marks]
Step 1: Instantaneous Power: Given i(t) = im sin(ωt). The instantaneous power dissipated across resistor R is:
p(t) = i²R = (im sin ωt)² R = im² R sin²(ωt). [1M]
Step 2: Cycle Average: Average power over period T: P = ⟨p⟩ = im² R ⟨sin² ωt⟩.
Using identity sin²(ωt) = ½ [1 - cos(2ωt)]:
⟨sin² ωt⟩ = ½ [1 - ⟨cos(2ωt)⟩] = ½ [1 - 0] = ½ (since cosine integrates to zero over full period).
Therefore, average power is P = ½ im² R. [2M]
Step 3: Definition of Equivalent Current I: Let I be the steady direct current producing the same power P = I² R:
I² R = ½ im² R ⇒ I² = im² / 2 ⇒ I = im / √2 = 0.707 im. [1M]
A8. AC Voltage Applied to Pure Inductor: Current & Power: [4 Marks]
Step 1: Kirchhoff's Loop Equation: v - L (di/dt) = 0 ⇒ L (di/dt) = vm sin(ωt) ⇒ di = (vm/L) sin(ωt) dt. [1M]
Integrating both sides: i(t) = (vm/L) ∫ sin(ωt) dt = - (vm / ωL) cos(ωt) + constant.
Since source oscillates symmetrically about zero with no DC bias, integration constant = 0.
Step 2: Phase Lag: Using trigonometric identity - cos(ωt) = sin(ωt - π/2):
i(t) = im sin(ωt - π/2), where current amplitude im = vm / (ωL) = vm / XL, with XL = ωL.
Comparing with v = vm sin(ωt), current lags voltage by π/2 rad (90°). [2M]
Step 3: Average Power Dissipated:
pL = v × i = [vm sin(ωt)] × [- im cos(ωt)] = - ½ vm im sin(2ωt).
Average over complete cycle: PL = - ½ vm im ⟨sin(2ωt)⟩ = 0 (since ⟨sin 2ωt⟩ = 0). Hence, power consumed is strictly zero. [1M]

Section C (Part II) Solutions • Advanced Circuit Derivations 10 Marks
A9. Series LCR Circuit: Phasor Analysis, Impedance & Resonance: [5 Marks]
Step 1: Phasor Representation: Let current phasor be I. Voltage phasors: VR = I R (in phase with I); VL = I XL (leads I by π/2); VC = I XC (lags I by π/2).
Combined reactive phasor has magnitude |VL - VC| = I |XL - XC| along the vertical axis. [1.5M]
Step 2: Pythagorean Vector Sum: Resultant source voltage phasor V = √[VR² + (VL - VC)²].
vm² = (im R)² + [im (XL - XC)]² = im² [R² + (XL - XC)²]
⇒ im = vm / √[R² + (XL - XC)²] = vm / Z, where impedance Z = √[R² + (XL - XC)²]. [1.5M]
Phase angle: tan φ = (VL - VC) / VR = (XL - XC) / R. [1M]
Step 3: Resonance Condition: At resonance, current amplitude is maximum, which requires minimum impedance:
XL = XC ⇒ ω0 L = 1/(ω0 C) ⇒ ω0² = 1/(LC) ⇒ ω0 = 1/√(LC).
Resonance requires both L and C so their opposite voltages (VL and VC, 180° out of phase) cancel each other. In pure RL or RC circuits, no cancellation is possible, so resonance cannot occur. [1M]
A10. Transformer Theory, Transformation Ratio & Energy Losses: [5 Marks]
(a) Principle: Works on the principle of mutual induction: an alternating current in the primary coil sets up a changing magnetic flux in the common soft iron core, which links and induces an alternating emf in the secondary coil. [1M]
(b) Mathematical Derivation: Let φ be magnetic flux per turn.
Induced emf in secondary: es = - Ns (dφ/dt); Back emf in primary: ep = - Np (dφ/dt).
Assuming zero primary winding resistance (Vp = ep) and open secondary (Vs = es):
Vs / Vp = Ns / Np.
For 100% efficiency, Power input = Power output: Vp Ip = Vs Is ⇒ Ip / Is = Vs / Vp.
Combining: Vs / Vp = Ns / Np = Ip / Is = k (transformation ratio). [2M]
(c) Types: Step-up transformer: Ns > Np ⇒ Vs > Vp, but Is < Ip. Step-down: Ns < Np ⇒ Vs < Vp, but Is > Ip. [1M]
(d) Energy Losses & Mitigation:
1. Eddy Current Loss: Changing flux induces eddy currents in solid core causing heating. Minimised by using a laminated soft-iron core insulated with varnish.
2. Joule Heating of Windings (I²R): Heat dissipated in copper coils. Minimised by using thick copper wire for high-current windings. [1M]
Section D Solutions • Step-by-Step NCERT Numericals 20 Marks
A11. Solutions to Bulb & Inductor Circuit (NCERT 7.1 & 7.2): [4 Marks]
(a) Bulb (P = 100 W, V = 220 V, ν = 50 Hz):
(i) Resistance: R = V² / P = (220)² / 100 = 48400 / 100 = 484 Ω. [1M]
(ii) Peak voltage: vm = √2 × V = 1.414 × 220 = 311.1 V. [0.5M]
(iii) RMS current: I = P / V = 100 / 220 = 0.455 A (or I = V/R = 220/484 = 0.455 A). [0.5M]
(b) Pure Inductor (L = 25.0 mH = 25 × 10¯³ H, V = 220 V, ν = 50 Hz):
(i) Inductive reactance: XL = 2πνL = 2 × 3.1416 × 50 × (25 × 10¯³) = 314.16 × 0.025 = 7.85 Ω. [1M]
(ii) RMS current: I = V / XL = 220 / 7.85 = 28.03 A ≈ 28 A. [1M]
A12. Solutions to Capacitor Circuit & Frequency Doubling (NCERT 7.4): [4 Marks]
Given: C = 15.0 μF = 15 × 10¯&sup6; F, V = 220 V, ν = 50 Hz.
(a) XC = 1 / (2πνC) = 1 / [2 × 3.1416 × 50 × (15 × 10¯&sup6;)] = 1 / (4.712 × 10¯³) = 212.2 Ω.
RMS current: I = V / XC = 220 / 212.2 = 1.04 A. [1.5M]
(b) Peak current: im = √2 × I = 1.414 × 1.04 = 1.47 A. [1M]
(c) Frequency Doubled (ν' = 2ν = 100 Hz):
Since XC ∝ 1/ν, capacitive reactance is halved: XC' = 212.2 / 2 = 106.1 Ω.
Current I' = V / XC' = 220 / 106.1 = 2.08 A (current is doubled). [1.5M]
A13. Solutions to Series LCR Circuit Analysis (NCERT Example 7.8): [6 Marks]
Given: vm = 283 V, ν = 50 Hz, R = 3 Ω, L = 25.48 mH = 25.48 × 10¯³ H, C = 796 μF = 796 × 10¯&sup6; F.
(a) Reactances:
XL = 2πνL = 2 × 3.1416 × 50 × 25.48 × 10¯³ = 314.16 × 0.02548 = 8.00 Ω.
XC = 1 / (2πνC) = 1 / [2 × 3.1416 × 50 × 796 × 10¯&sup6;] = 1 / 0.250 = 4.00 Ω. [1.5M]
(b) Impedance:
Z = √[R² + (XL - XC)²] = √[3² + (8 - 4)²] = √[9 + 16] = √25 = 5.00 Ω. [1.5M]
(c) Phase Difference:
tan φ = (XL - XC) / R = (8 - 4) / 3 = 4/3 = 1.333 ⇒ φ = tan¯¹(1.333) = +53.1° (or +0.927 rad).
Since XL > XC, the circuit is predominantly inductive; current lags voltage by 53.1°. [1.5M]
(d) Power Factor & Power Dissipated:
Power factor: cos φ = R / Z = 3 / 5 = 0.60.
Peak current: im = vm / Z = 283 / 5 = 56.6 A ⇒ Irms = im / √2 = 56.6 / 1.414 = 40.0 A.
Average power: P = Irms² R = (40)² × 3 = 1600 × 3 = 4800 W = 4.80 kW. [1.5M]
A14. Solutions to Resonance & Transformer Calculation (NCERT 7.9 & 7.8): [6 Marks]
(a) Resonance Analysis (L = 25.48 mH, C = 796 μF, R = 3 Ω, vm = 283 V):
Resonant angular frequency: ω0 = 1/√(LC) = 1/√(25.48 × 10¯³ × 796 × 10¯&sup6;) = 1/√(2.028 × 10¯&sup5;) = 222.1 rad/s.
Linear resonant frequency: νr = ω0 / (2π) = 222.1 / (2 × 3.1416) = 35.4 Hz.
Impedance at resonance: Z = R = 3.0 Ω.
RMS current at resonance: Ires = Vrms / R = (283 / √2) / 3 = 200.1 / 3 = 66.7 A.
Power dissipated at resonance: Pres = Ires² R = (66.7)² × 3 = 4448.9 × 3 = 13347 W ≈ 13.35 kW. [3.5M]
(b) Transformer (Np = 100, Ns = 200, Vp = 220 V, Ip = 10 A):
Turns ratio: k = Ns / Np = 200 / 100 = 2.
Secondary voltage: Vs = (Ns / Np) × Vp = 2 × 220 V = 440 V.
Secondary current: Is = (Np / Ns) × Ip = (100 / 200) × 10 A = 5.0 A. [2.5M]
