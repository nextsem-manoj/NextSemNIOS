## 📝 Problem Statement (Question 1)

**Business Name:** M/s Nextsem Infotech & Electronics, New Delhi  
**Transaction Date:** April 04, 2026  
**Supplier:** M/s Modern Electronics, Nehru Place, Delhi (Invoice No. 401)  

**Details of Goods Purchased on Credit:**
1. **20 Laptops** @ ₹30,000 each
2. **15 Desktop Monitors** @ ₹8,000 each
3. **Trade Discount** allowed @ 10%
4. **GST Rates:** CGST @ 9% and SGST @ 9%

---

## 🧮 Step-by-Step Mathematical & Accounting Calculations

1. **Calculate Gross Invoice Value:**
   - 20 Laptops $\times$ ₹30,000 = ₹6,00,000
   - 15 Desktop Monitors $\times$ ₹8,000 = ₹1,20,000
   - **Total Gross Amount** = ₹6,00,000 + ₹1,20,000 = **₹7,20,000**

2. **Deduct Trade Discount (10%):**
   - Trade Discount = $10\% \text{ of } ₹7,20,000 = \mathbf{₹72,000}$
   - **Net Taxable Cost / Purchases Value** = ₹7,20,000 - ₹72,000 = **₹6,48,000**

3. **Calculate Goods & Services Tax (GST):**
   - **Input CGST @ 9%** on ₹6,48,000 = $\frac{9}{100} \times 6,48,000 = \mathbf{₹58,320}$
   - **Input SGST @ 9%** on ₹6,48,000 = $\frac{9}{100} \times 6,48,000 = \mathbf{₹58,320}$
   - **Total GST** = ₹58,320 + ₹58,320 = **₹1,16,640**

4. **Calculate Total Invoice Amount (Payable to Supplier):**
   - Total Payable = Net Cost (₹6,48,000) + Input CGST (₹58,320) + Input SGST (₹58,320)
   - **Total Amount** = **₹7,64,640**
